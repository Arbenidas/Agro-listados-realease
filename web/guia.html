Guía de uso paso a paso

En pocos minutos aprenderás a crear tu primera lista de productos, añadir artículos con su precio y cantidad, y exportar el documento final. No necesitas conocimientos técnicos ni instalar ningún programa.

1. Elige un punto de venta

Al abrir la aplicación verás la pantalla de inicio con el buscador de puntos de venta. Escribe el nombre del punto (por ejemplo, el nombre de un mercado, cliente o ruta) y toca la tarjeta correspondiente. Cada punto de venta tendrá su propia lista independiente, de modo que puedas mantener separados los pedidos de cada destino.

2. Añade productos a la lista

Dentro de la lista, usa el botón de añadir para incorporar productos. Para cada uno puedes indicar:

  • Nombre del producto (por ejemplo, tomate, papa, lechuga).
  • Unidad de medida: kilogramo, caja, bulto, docena, unidad, etc.
  • Precio por unidad.
  • Cantidad que se despachará.

A medida que completas los datos, Agro-listados calcula automáticamente el subtotal de cada producto y el total general de la lista, para que siempre tengas el monto a la vista.

3. Usa la carga masiva para ir más rápido

Si necesitas registrar muchos productos a la vez, entra a la opción de entrada masiva. Allí puedes recorrer un listado amplio de productos y asignar cantidades y precios de forma continua, sin abrir un formulario para cada uno. Es la forma más rápida de armar listas largas.

4. Importa y exporta en CSV

  1. Importar CSV: desde el menú de la lista puedes cargar un archivo CSV con productos ya preparados. Es útil si partes de una plantilla o de datos de otro sistema.
  2. Exportar CSV: genera un archivo con los productos de la lista actual para reutilizarlos, respaldarlos o abrirlos en tu hoja de cálculo preferida.

5. Exporta a PDF o Excel

Cuando la lista esté lista, exporta el documento final:

  • PDF: ideal para imprimir o enviar por mensajería; muestra los productos, cantidades, precios y totales de forma ordenada.
  • Excel: útil si quieres seguir trabajando los datos o combinarlos con otros informes.
  • Exportar todo (ZIP): si manejas varias listas, puedes descargarlas juntas en un solo archivo comprimido.

6. Continúa donde lo dejaste

Agro-listados guarda tu trabajo en el navegador. Si cierras la pestaña y vuelves más tarde, en la pantalla de inicio verás la opción “Continuar editando listas” para retomar tu sesión anterior.

Consejos rápidos

  • Crea un punto de venta distinto por cada cliente o ruta para no mezclar pedidos.
  • Duplica una lista existente cuando dos clientes lleven pedidos parecidos.
  • Revisa los totales antes de exportar para evitar errores de precio o cantidad.
  • Exporta a CSV como respaldo si vas a limpiar o reiniciar tus listas.
